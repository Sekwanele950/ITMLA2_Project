# ITMLA2-44 Machine Learning Algorithms - Project

## Project Overview
This repository contains the individual project submission for the **ITMLA2-44 Machine Learning Algorithms** module at Eduvos[cite: 2, 11]. The project covers predictive maintenance modeling, feature selection, custom gradient descent implementation, and smart-building clustering[cite: 3, 4, 5].

## Repository Structure
* `data/` - Contains the dataset CSV files (`machine_service_risk.csv`, `grid_restoration.csv`, `smart_building_profiles.csv`)[cite: 3, 5, 6].
* `notebooks/` - Jupyter Notebooks containing Python code and analysis.
* `docs/` - Assignment instructions, assignment template, and AI Disclosure Appendix[cite: 2, 3].

Developed using Python (Anaconda distribution)[cite: 10] utilizing libraries such as:
